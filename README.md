### 三个安卓开源工具

| 项目 | 是什么 | 拿到它 |
|---|---|---|
| [**wpaforge**](https://wlmosv.dpdns.org/wpaforge/) | 安卓原生 Wi-Fi 弱口令审计，不用电脑也不用外置网卡 | [下载 APK](https://wlmosv.dpdns.org/dl) |
| [**TGAutoSign**](https://wlmosv.dpdns.org/tgautosign/) | Telegram 每日自动签到，管理面板就在聊天里 | [下载 APK](https://wlmosv.dpdns.org/dl/tgautosign) |
| [**apk-index**](https://wlmosv.dpdns.org/apk-index/) | 本地 APK / DEX 结构索引，通过 MCP 交给 AI 客户端 | [源码 / 安装](https://github.com/wlmosv-png/apk-index) |

**[wlmosv.dpdns.org](https://wlmosv.dpdns.org)** — 每个项目都有独立的详情页，装之前可以先看看它具体能做什么、什么时候会失败。
