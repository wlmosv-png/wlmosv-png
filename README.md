我在做 **Android 系统层的工具**——root、Xposed、逆向，以及把「本该在电脑上做的事」搬进手机。

### 在做的东西

| 项目 | 是什么 | 为什么做 |
|---|---|---|
| **[WPAForge](https://github.com/wlmosv-png/wpaforge)** | Android 无线网络安全自查工具 | 想验证自家路由器的口令强度，但现成的工具都得先把抓包丢到电脑上算 |
| **[TGAutoSign](https://github.com/wlmosv-png/TGAutoSign)** | Telegram 自动签到 Xposed 模块 | 签到太烦；而「群签到到底算不算成功」比想象中难判定得多 |
| **[apk-index](https://github.com/wlmosv-png/apk-index)** | APK 静态索引与逆向检索 | 逆向时定位一个 hook 点，不该靠人肉翻 smali |

三个都是**我自己每天在用**才做的。不接需求、不排期，改到够用为止。

### 做东西时的几条底线

- **判定宁可慢，也要有据可查**——不接受「大概是吧」
- **失败要说清是哪儿失败了**，而不是只丢一个 error
- **只做一件事，但把它做干净**——不需要的功能不加
- 不上传用户数据。能在本机算完的，就不联网
